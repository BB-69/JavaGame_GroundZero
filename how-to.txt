How to Build a Game on Top of This

Step 1: Add a Player
- Extend Entity
- Update position in update()
- Draw sprite or rectangle in render()

Step 2: Add Input
- Query InputHandler inside update()
- Move player based on keys

Step 3: Add States
- Create MenuState, PlayState, etc.
- Switch states via StateManager

Step 4: Add Assets
- Load images via ImageIO.read()
- Cache them once in init()

Step 5: Improve Timing
- Switch to delta time if you want variable FPS
- Or keep fixed FPS for pixel-perfect movement
